# Quantum Circuits with Qiskit
This project explores basic quantum circuits and their mathematical structure using Qiskit.

## Concepts covered
- Quantum circuits (Rz rotation, Hadamard gate)
- Statevector simulation
- Unitary operators
- Density matrices
- Relationship between circuit and linear algebra

## Key idea
A quantum circuit corresponds to a unitary operator U, and the final state is:
|ψ⟩ = U |0⟩

## Example
We construct a circuit:
Rz(π/2) → H

and compute:
- its statevector
- its operator (matrix form)
- its density matrix

## Goal
Bridge theoretical quantum computing (geometry, ZX-calculus) with practical implementation.
